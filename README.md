
# RetailFlow

A Java-based retail inventory and sales management
system developed for the Programming 2 OOP assignment
at the University of Pécs.

## Technologies
- Java 26
- Maven
- IntelliJ IDEA

## Project Objectives
- Manage retail products and inventory
- Process sales transactions
- Demonstrate object-oriented programming principles
- Save and restore application data
- Apply appropriate software design patterns

## Development Status
Initial project setup completed.

## Build Instructions
Run the following command:

mvn clean package
